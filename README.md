# 灵动岛挂件 (Dynamic Island Widget) — Windows

把 iOS 灵动岛带到 Windows 桌面的独立小程序:一个悬浮在屏幕顶部的灵动岛,
自动感知当前正在播放的音乐(QQ音乐 / 网易云音乐 / 酷狗 / 酷我 / 汽水音乐 /
浏览器标签页音频等),可展开成控制面板,进度、切歌、播放模式一手掌控;
也可以切换到 **Agent 模式**,变成"岛灵"——一个常驻桌面的 LLM 助手,
直接对话就能让它执行本机操作、并主动向用户介绍它有什么功能。

- **音乐模式**:SMTC 系统媒体监听 + 本地播放器双轨,歌词字幕、主题色、
  自定义背景、字体库、时间粒子,复刻 iOS 灵动岛的观感与手感。
- **Agent 模式**:LLM 对话 + 本机工具执行(命令 / 文件 / 浏览器 / 搜索 /
  通知 / B站下载 / 文档转换 / 超星答题),可挂 MCP 服务、技能、长期记忆,
  甚至让记忆自我进化;支持主动陪伴、心理揣测、多媒体库。
- **对话即功能引导**:问岛灵"你有什么功能",它会读取内置技术文档
  (docs/TECH.md)按你的兴趣介绍和引导使用。

技术栈:**Electron 43 + React 19 + TypeScript + Vite**,通过 Windows 系统媒体
会话(SMTC)与系统媒体交互。项目当前处于**源码运行/开发阶段**(不提供安装
发行版),运行方式见[快速开始](#快速开始)与[开发与构建](#开发与构建)。

> 开发者与详细技术说明见 [docs/TECH.md](docs/TECH.md)(约 3000 行技术文档)
> 与 [WIDGET-README.md](WIDGET-README.md)(挂件部署/调试说明)。

## 快速开始

### 获取与运行

项目以**源码方式运行**(当前不提供安装发行版),需要 Node.js 环境:

1. 安装依赖:`pnpm install`;
2. 启动挂件:双击项目根目录的 **`dev.bat`**(一键重新构建并启动:自动结束
   残留旧实例 → 重新构建 → 启动 Electron,灵动岛出现在屏幕顶部居中);
   或手动执行 `pnpm dev:widget`(效果等价)。

### 启动与退出

- 双击程序即可启动,灵动岛出现在屏幕顶部居中;
- 退出:右键托盘图标 →「退出」;托盘图标常驻(设置、模式切换、多媒体库、
  置顶都在托盘菜单里)。

### 运行环境

- Windows 11(26100 或更新推荐;SMTC 桥接依赖新版 WinRT API);
- 音乐控制需要目标播放器支持 Windows 系统媒体会话(SMTC)——QQ音乐、
  网易云、酷狗、酷我、浏览器(Chrome/Edge 标签页)等均支持;
- Agent 模式需要可用的 LLM API(默认 DeepSeek,也可用 Anthropic 兼容端点)。

## 界面与基础操作

### 手势一览(音乐模式)

| 手势 | 效果 |
| --- | --- |
| 单击岛体 | 展开 / 收起控制面板 |
| 右键长按(≈0.4s)后拖动 | **移动挂件**(位置自由,不限制在屏幕内) |
| 快速右键点击/拖动 | 无效果(只属于拖拽) |
| 悬停紧凑岛 | 临时展开进度条 |
| 展开态长按空白 | 3D 压感回弹(音乐模式) |

> Agent 模式:展开面板后**单击/长按/Esc 均不收起**(防止误触),收起唯一
> 入口 = 面板右上角 ⋯ 菜单的「收起为灵动岛」/「收起为多媒体岛」。

### 数据源切换

优先使用系统正在播放的外部平台(SMTC);本地播放器兜底。切换数据源时
双向暂停,避免双声齐响。

### 模式切换(音乐 ↔ Agent)

- **托盘**:右键托盘图标 →「模式」→ 音乐模式 / Agent 模式(持久化,
  重启恢复);
- **对话中**:对岛灵说"切回音乐模式"或"听歌"——切换模式时会自动从当前播放列表开始播放(switch_to_music 工具带 play)。

## 音乐模式使用指南

### 展开面板布局

展开后面板包含:歌名/歌手、进度条(可拖拽)、上一首/下一首、播放/暂停、
循环模式、歌词字幕、播放键下方提示(歌词厂商名)。

### 进度条与跳转

- 点击/拖动进度条 seek(左键);不支持 seek 的平台(如部分浏览器)会提示
  并回退;
- seek 能力按平台记忆(切换平台/重启不重学)。

### 播放模式

点击循环按钮切换(顺序 / 单曲循环 / 随机),以系统真实状态为准;点击后
1.2s 检测是否跟随,没跟随则提示并回退。

### 歌词字幕

- 展开面板可开关歌词;歌词来源按监听平台自动匹配(QQ音乐→QQ歌词 等),
  也可在设置「歌词 API」手动指定(QQ / 网易云 / 酷狗 / 酷我 / 自定义 URL
  模板);
- 浏览器等无公开歌词 API 的平台回退手动配置。

### 本地播放器与上传音乐

- 点击展开面板的上传按钮选择本地音乐(可多选),存入播放列表并自动播放;
- 播放列表持久化,重启不丢;上传的歌曲会自动补录到多媒体库音频库。

### 时间粒子

展开态背景有时间粒子氛围效果。

## Agent 模式使用指南

### 首次使用(必读)

1. 托盘切到 **Agent 模式**;
2. 展开岛体 → 打开 Agent 面板 → 点 ⋯ 菜单「设置」→「连接」组填入
   API Key(和 Base URL / 模型,如需自定义);
3. 回来直接对话。

> 默认接入 DeepSeek(Responses API,模型 deepseek-v4-flash);Base URL 含
> "anthropic" 自动切换 Anthropic Messages 协议,含 "chat" 切换 Chat
> Completions。API Key 经系统 DPAPI 加密落盘。

### 对话界面

- 用户消息右气泡(强调色)、助手消息左气泡(半透明白底);
- 工具调用按回复**收纳成单一汇总列表**(默认折叠,点击展开看每张卡片、
  卡片里再展开参数)——工具不夹在文本段之间;
- 输入框:Enter 发送(IME 组字不触发)、Shift+Enter 换行;运行中变"停止";
- 消息气泡支持 **Markdown 渲染**:表格 / 代码块(可复制)/ 链接 / 列表 /
  Mermaid 图表;
- 回复完成后自动总结对话标题,紧凑态文字区显示心理揣测 / 标题 / 回复
  预览;
- **窗口高度随对话 1:1 展开**:消息多长窗口多高(逐行跟随),最多到
  宽度的 16:9 后封顶、消息列表滚动;界面放大只放大宽度,高度跟随内容。

### 头部 ⋯ 菜单

| 项 | 说明 |
| --- | --- |
| 停止生成 | 运行中显示,中止当前回合 |
| 新对话 | 当前对话自动存档后清空(正在运行的回复一并中止,不会落进新对话) |
| 对话历史 | 查看/加载/删除历史会话(最多 20 条) |
| 工具列表 | 全部工具一览(含 MCP / 技能,参数可展开) |
| 多媒体库 | 打开图片/音频/视频库 |
| 设置 | Agent 设置(连接/行为/工具/记忆/Sub Agent) |
| 收起为灵动岛 | 收起为 Agent 紧凑态(不生成媒体岛) |
| 收起为多媒体岛 | 收起为视频/图片小窗(正在播放的媒体) |

### 手动调用技能与 MCP 工具

- 输入以 `/` 开头 = 调技能(如 `/poem-writer`);
- 输入以 `@` 开头 = 调 MCP 工具(如 `@mcp_filesystem_read_file`);
- 输入 `/` 或 `@` 时自动浮出候选列表(↑↓ 导航 / Enter 选中 / Esc 关闭);
- 剩余文本是合法 JSON 对象则作为工具参数。

### MCP 服务接入

- 设置 → Agent 设置 → 工具与能力 → MCP 服务:添加 stdio / sse 服务
  (名称/命令或 URL/参数/环境变量/请求头),逐条「测试」连通;
- 工具自动注册为 `mcp_服务名_工具名`,对话中可直接调用;
- 也可以在对话里直接说"添加一个 MCP 服务,命令是 …"。

### 技能系统

- 自动扫描 `~/.claude/skills`、`~/.codex/skills`、`~/.config/opencode/
  skills`、`userData/skills` 中的 SKILL.md,注册为 `/技能名`;
- 对话里说"创建一个写诗技能"即可让 LLM 自己创建技能;
- 设置界面可导入技能包、分区管理(灵动岛创建 / 手动导入 / 扫描到的);
- **灵动岛创建分区支持彻底删除**(两段确认,从磁盘移除,不进恢复区);
  扫描到的外部技能只能"移除"(排除,可恢复)。

### 长期记忆系统

- 对话中"记住:…"写入长期记忆(偏好/事实/工作流/教训四类);
- 设置 → 长期记忆:条目增删改查、类型定制、导入导出;
- 记忆内容参与每轮系统提示(助手记得"你是谁")。

### 自我进化

- 设置 → 自我进化:「运行记忆进化」对长期记忆自动评估优化(评审 → 候选
  → 接受),版本化快照可回滚、可清除全部版本;
- **垂直细分整合**:重复/相似的记忆(同一主题的多条)会自动合并为一条
  垂直细分条目(如"TTG/小胖偏好"、"夜间作息"各自只剩一条),关键词不再
  散落重复出现在多条记忆里;清理类改动由评审直接确认落地;
- 后台运行,完成系统通知;对话里 LLM 可感知进化结果。

### 主动陪伴

- 用户长时间无操作时,岛灵主动开口(默认开启,间隔 15 分钟,可改);
- 判断偏保守(不打扰是安全侧);需要真实信息时会主动调用工具查证/办事
  (更拟人,2026-08-10 起);
- 主动消息 = Windows 系统通知 + 紧凑态文字区心理揣测;
- 设置 → 主动陪伴:开关 / 触发间隔(15/30/60/120 或自定义)/ 单位
  (秒/分钟/小时);也可对话里说"把主动陪伴关掉"。

### 对话历史与标题

- 每轮回复完成后自动总结标题(心理揣测 → 标题 → 回复预览 优先显示);
- ⋯ 菜单「对话历史」查看/加载;「新对话」开启新会话(自动存档)。

### Agent 设置(全部字段)

**连接**:账户余额卡片(进入自动查询,可刷新/去充值)/ 协议提示(自动检测)/ API Key / Base URL / 模型 / 思考强度
(关/低/中/高)/ 输出预算(4096-262144,缺省 8192,LLM 也可自行调整)。

**行为与界面**:自定义提示词(与长期记忆共同构成系统提示)/ 主动陪伴 /
界面放大(100-300%,只放大面板与窗口,文字按钮不缩放)/ 媒体窗口默认宽
(240/320/480/640 或自定义)。

**工具与能力**:MCP 服务 / 技能目录(移除可恢复;灵动岛创建分区可彻底删除)。

**记忆与进化**:长期记忆 / 自我进化。

**Sub Agent**:总结标题文风(简洁/活泼/文艺/正式/自定义)+ 心理揣测人格
(猫娘/温柔/高冷/风趣/自定义)。

## 多媒体库

独立于设置的媒体管理面板(托盘 → 多媒体库…,或 Agent ⋯ 菜单):

- **图片**:浏览图片库、改名/删除/上传;右键图片 →「应用到展开态/紧凑态
  背景」(直接当背景用,返回键回多媒体库);
- **音频**:试听(定制播放条)、改名/删除、单个/批量导入播放列表(导入后
  自动切回音乐模式播放)、上传本地音乐;
- **视频**:岛内直接播放(流式,支持大文件)、改名/删除、导入本地视频;
  **同时播放多个视频可各自独立调整音量/倍速/循环**(互不影响);
- **自动播放只在媒体第一次加载到对话窗口时触发**(LLM 播放的视频/音频
  会自动播放);之后**滚动重挂载不再自动播放**;**收起为多媒体岛后切回
  对话窗口:视频岛播放中会从原进度继续播放**(播放状态同步),小窗暂停后
  切回则停在原进度、需手动播放;
- **收起为多媒体岛 = 媒体元素同尺寸小窗**:小窗大小与对话窗口里的媒体
  元素一模一样,切回对话窗口保持相同尺寸;
- 对话里也可以让 LLM 操作:"导入 D:\xx.mp3 到音频库""播放视频库里的
  XX 视频"(自动跳转到多媒体库并播放)、"把第二个视频音量调到 30%、
  暂停它"(set_video_config 带视频名独立控制)。

## 个性化外观

设置视图(托盘 → 设置…)入口:背景 / 主题色 / 字体 / Agent 设置 / 歌词 API。

- **主题色**:强调色(按钮/气泡/进度条/开关等),自定义任意颜色;
- **自定义背景**:展开态与紧凑态**各自独立**的图片/不透明度/裁切,
  岛内取景编辑;
- **字体库**:导入 ttf/otf/woff/woff2(≤30MB),搜索/改名/删除/应用;
- **文字颜色**:自动(按背景亮度黑白)或自定义(色板 + 岛内自绘取色器);
- **对话直达**:对岛灵说"把岛调成紫色""界面放大到 150%""用这张图当
  背景"——设置工具即时生效,无需进设置界面。

## QQ 远程控制(NapCat 机器人)

> 2026-08-12:灵动岛 LLM 接管 QQ 消息——**挂件启动 + 开启后**,私聊/群聊消息自动进入Agent 对话窗口(同步上下文与长期记忆),由 LLM 自主回复;挂件未启动时不自主回复。

### 开启方式

1. 启动 [NapCat](https://napneko.github.io)(OneBot 11,默认 WS `ws://127.0.0.1:3001`);
2. 在对话窗口对岛灵说 **"开启 QQ 机器人"**(`set_napcat_config`,可同时指定 WS 地址);
3. 对话里说"QQ 连上了吗"可查连接状态(`napcat` 工具 status)。

### 消息处理规则

| 来源 | 行为 |

## 常见问题

**Q: 岛灵一直空参调用工具 / 回复总被截断?**
A: 思考模式高 effort 会吃光输出预算——对话里说"调大输出预算"或把思考
强度调低;LLM 也可自行用 set_output_budget 调整(2026-08-08 起)。

**Q: B站下载失败?**
A: 先扫码登录(对话里说"B站登录一下",窗口内展示二维码,手机 B站 App
扫码);下载落点在 userData/bili/downloads/。

**Q: QQ 机器人不回复?**
A: 确认① 对话里说过"开启 QQ 机器人"并查连接状态("QQ 连上了吗");② NapCat 已启动且 WS 端口开放;③ 旧 Python 桥已停用;④ 白名单包含对方 QQ。

**Q: 群里消息会泄露我的私聊吗?**
A: 不会——群/陌生人回复带隐私边界指令,LLM 不透露你的私密信息;你可以在对话窗口随时介入纠正。

**Q: 主动陪伴不触发?**
A: 检查设置开关、间隔(默认 15 分钟)、是否 Agent 模式、是否有对话历史;
判断偏保守是安全侧设计。

**Q: 界面缩放后文字没变大?**
A: 缩放只放大面板/窗口尺寸,UI 元素(文字/按钮)不缩放——用户明确要求
(让程序大一点、眼睛不累)。

**Q: 对话消息多了滚动卡顿/滚动条抽搐?**
A: 已用虚拟滚动解决(2026-08-12):消息列表只挂载可视区附近的几十条,
几百条历史消息的滚动条也按真实内容比例稳定显示,滚动流畅。若仍卡顿,
多为播放中的视频(软件解码)或超大媒体消息,拖完/播完即恢复。

**Q: 改了引擎没生效?**
A: 重跑 build:electron(dev:widget 已前置)。

**Q: 视频"无法播放"?**
A: 窗口内支持 H.264/HEVC(H.265)/AV1 的 mp4 与 webm/ogg。HEVC/AV1 靠
自编译 ffmpeg 软解(dev.bat 自动应用 `scripts/apply-hevc-electron.mjs`,
官方版备份可回退);其余格式(mkv/avi/flv 等)点错误提示按钮用系统
播放器打开降级。

## 开发与构建

### 命令

```bash
dev.bat              # 一键重新构建并启动桌面开发版(双击即可):结束旧实例
                     # (单实例锁,不结束则新启动只唤起旧窗口) → 重新构建 →
                     # 启动 Electron;真实逻辑在 scripts/dev.mjs,中文不乱码
pnpm dev             # 仅 Web 演示版(浏览器调试,不进 Electron)
pnpm dev:widget      # 构建挂件页面并启动 Electron(日常调试主入口)
pnpm build           # tsc -b 类型检查 + Web 版构建
pnpm build:widget    # 仅构建挂件页面
pnpm build:electron  # esbuild 打包 Agent 引擎 + SMTC 桥
pnpm lint            # oxlint
pnpm bridge          # 独立运行系统媒体桥接脚本(单独调试 SMTC)
pnpm watch:electron  # 热重建 Agent 引擎/桥
node tests/test-agent-core.mjs   # 引擎核心测试(109 用例)
pnpm test:markdown    # Markdown 解析器测试(39 断言)
```

### 验证约定

每次修改后:构建 + dev:widget 启动 + 类型检查 + lint + 单测;完整 UI 巡检
(WIDGET_SCREENSHOT,agent 模式等)只在明确要求时执行。
