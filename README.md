# 灵动岛挂件 (Dynamic Island Widget) — Windows

把 iOS 灵动岛带到 Windows 桌面的独立小程序:一个悬浮在屏幕顶部的灵动岛,
自动感知当前正在播放的音乐(QQ音乐 / 网易云音乐 / 酷狗 / 酷我 / 汽水音乐等),
可展开成控制面板,进度、切歌、播放模式一手掌控;也可以切换到 **Agent 模式**,
变成"岛灵"——一个常驻桌面的 LLM 助手,直接对话就能让它执行本机操作。

- **音乐模式**:SMTC 系统媒体监听 + 本地播放器双轨,歌词字幕、主题色、
  自定义背景、字体库、时间粒子,复刻 iOS 灵动岛的观感与手感。
- **Agent 模式**:LLM 对话 + 本机工具执行(命令 / 文件 / 浏览器 / 搜索 /
  通知 / B站下载 / 文档转换 / 超星答题),可挂 MCP 服务、技能、长期记忆,
  甚至让记忆自我进化。

技术栈:**Electron 43 + React 19 + TypeScript + Vite**,通过 Windows 系统媒体
会话(SMTC)与系统媒体交互,打包为免安装的便携版与 NSIS 安装版。

## 快速开始

### 获取

打包产物在 `release/` 目录(或从 GitHub Releases 下载),二选一:

| 产物 | 说明 |
| --- | --- |
| **灵动岛挂件-便携版-1.0.0.exe** | 免安装,双击即用(推荐) |
| **灵动岛挂件-安装版-1.0.0.exe** | NSIS 安装程序,可选安装目录,开始菜单创建「灵动岛挂件」与「卸载 灵动岛挂件」快捷方式 |

### 启动与退出

- 便携版:双击 exe 即启动,挂件出现在屏幕顶部居中。
- 安装版:按向导安装后从开始菜单启动。
- 退出:托盘图标 → 右键 → 「退出」;卸载安装版时**会连同用户数据一并删除**
  (上传的音乐、自定义背景、字体、Agent 配置与记忆)。

### 运行环境

- Windows 10 / 11(系统媒体读取依赖 `System32\WinMetadata`)。
- 系统媒体监听需要对应音乐客户端**正在播放**(支持 SMTC 的客户端:
  QQ音乐、网易云音乐、酷狗、酷我、汽水音乐等;浏览器播放也会被识别,
  但部分上报不稳定)。

## 界面与基础操作

挂件平时是**点击穿透**的:鼠标在岛体之外时直接穿透到下层窗口,
鼠标移入岛体后才接收点击。它始终浮在桌面上,不抢焦点、不挡操作。

### 手势一览(音乐模式)

| 操作 | 功能 |
| --- | --- |
| **悬停岛体** | 岛体横向微展,露出进度条,可点击 / 拖动跳转播放进度 |
| **长按岛体** | 展开成控制面板(播放控制 / 歌词 / 上传入口) |
| **单击岛体(展开时)** | 收起面板,回到胶囊 |
| **双击文字** | 播放 / 暂停 |
| **左右滑动文字** | 上一首 / 下一首 |
| **右键长按拖拽岛体** | 按住右键约 0.4 秒后拖动,移动挂件位置(快速右键点击/拖动无效果) |
| **拖动进度条** | 时间粒子效果:拖动时文字区显示粒子拼成的时间 |

### 数据源切换

岛体展开面板左上角为音乐图标按钮,点击在 **「系统监听 ↔ 本地播放器」** 间切换:

- **系统监听(默认)**:读取正在播放的外部客户端(SMTC),跟随其曲目与进度,
  控制指令发给该客户端。
- **本地播放器**:播放你自己上传的音乐,控制指令由挂件自己完成。

切换时**双向暂停**(切走的一方自动暂停),避免两个播放器同时出声。

### 模式切换(音乐 ↔ Agent)

托盘右键 → 「模式」→ 音乐模式 / Agent 模式(单选项,选择即切换,持久化,
下次启动恢复)。切换时:

- 切到 Agent 模式:岛体变成四角星图标,长按展开对话面板。
- 切回音乐模式:若 LLM 正在回复,本轮会被中止。

## 音乐模式使用指南

### 展开面板布局

长按岛体展开面板,自上而下:

| 区域 | 内容 |
| --- | --- |
| 头部 | 歌名 / 歌手、播放状态、数据源切换按钮(音乐图标)、主题色按钮、⋯ 更多 |
| 控制区 | 上一首 / 播放暂停 / 下一首、播放模式(顺序 / 单曲循环 / 随机) |
| 进度条 | 当前时间 / 总时长,点击或拖动跳转 |
| 歌词区 | 自动查询的歌词,当前句高亮(可关闭) |
| 播放键下方 | 平台不支持操作时的岛内提示(如"该平台不支持进度跳转") |

### 进度条与跳转

- 悬停岛体露出进度条,点击任意位置跳转、按住拖动连续跳转。
- 跳转依赖客户端支持 SMTC 跳转指令:**QQ音乐等客户端不支持**,
  点击后岛内提示并自动回退(进度条仍显示系统真实状态)。
- 显示进度 = 锚定基准 + 本地时钟流逝,平滑无回跳;平台位置上报不可信时
  (浏览器标签页播放)自动走平滑模型,不会抽搐。

### 播放模式

- **本地播放器**:顺序 / 单曲循环 / 随机,始终有效。
- **外部平台**:走 SMTC 新版 API 指令,客户端不支持时指令被拒并提示,
  岛体始终显示系统真实模式状态(点击循环后 1.2 秒检测是否跟随)。

### 歌词字幕

展开面板自动按当前曲目(歌名 / 歌手)查询 LRC 歌词并高亮当前句。

- **预设歌词源**:QQ音乐(默认)/ 网易云音乐 / 酷狗音乐 / 酷我音乐 /
  自定义 URL 模板(`{title}` / `{artist}` 占位)。
- **按监听平台自动切换**(默认开启):QQ音乐 → QQ 源,网易云 → 网易云源,
  酷狗 → 酷狗源,酷我 → 酷我源;浏览器等无对应歌词 API 的平台回退手动配置。
  可在 设置 → 歌词 API 中关闭自动切换、手动固定歌词源。
- 歌词查询带缓存;切换歌词源后立即重新查询当前歌曲。
- 设置视图的「歌词 API」入口可切换预设、保存、配置自定义 URL 模板。

### 本地播放器与上传音乐

- 播放列表只包含你上传的音乐(内置测试曲目已移除)。
- 展开面板主体在空列表时直接显示上传入口,点击选择文件上传
  (音频格式均可,持久化保存在 IndexedDB)。
- 支持顺序 / 单曲循环 / 随机三种播放模式。
- 播放列表只对本地播放器有效——外部平台(SMTC)不提供播放列表读取能力。

### 主题色自定义

展开面板 → 调色盘按钮进入主题色视图:

- 左侧预设色板(跟随播放模式的动态色 + 7 个常用色);
- 右侧 RGB 数字输入,输入即生效(无弹出层);
- 切换颜色时岛体触发柔和涟漪动画;
- 主题色持久化(localStorage),Agent 模式自动使用自定义色(默认 `#4d6bfe`)。

### 自定义背景

托盘右键 → 「设置…」→ 「自定义背景」(或设置视图内入口),在灵动岛内打开
编辑视图:

- **展开态与紧凑态各自独立**:图片、不透明度、裁切(位置 / 缩放)分别设置,
  切换形态时自动套用对应配置。
- 上传图片自动降采样(长边 ≤ 1024px,防形变动画卡顿),持久化(IndexedDB)。
- 不透明度滑杆拖动实时预览;裁切视口支持拖动取景。
- 编辑控件压在背景图上的蒙版保证可读性;蒙版不透明度统一 0.55。
- 上传的背景自动进入**图片库**(见下)。

### 字体库与字体颜色

设置视图 → 「字体」:选择字体文件(ttf / otf / woff / woff2,≤ 10MB)应用
到岛体文字,可编辑名称、删除、上传入库(**字体库**多条目管理)。

字体颜色两种模式:

- **自动**:按背景图合成亮度自适应(背景亮 → 黑字,背景暗 → 白字),
  随当前形态(展开 / 紧凑)分别判断;
- **自定义**:进入独立颜色页,内置色板 + **岛内自绘取色器**(饱和 / 明度面 +
  色相条,拖动取色)+ hex 输入,不弹系统对话框;字体颜色与主题色共用取色器。

### 图片库

设置视图 → 「图片库」:所有上传过的背景图以网格展示,支持搜索、点击应用、
重命名、删除。图片库与背景编辑器互通(背景上传自动入库)。

### 设置视图(音乐相关)

托盘右键 → 「设置…」打开,包含:

| 入口 | 内容 |
| --- | --- |
| 歌词 API | 预设歌词源切换 / 自动切换开关 / 自定义 URL 模板 |
| 自定义背景 | 上传、双形态图片与裁切编辑(见上) |
| 主题色 | 预设色板 + RGB 输入 |
| 字体 / 字体颜色 / 字体库 | 字体文件管理与文字颜色 |
| 图片库 | 背景图多条目管理 |
| 帮助手册 | 内置操作说明 |
| Agent 设置 | Agent 模式配置(见下一节) |

设置类视图只能通过返回键退出(屏蔽单击 / 长按 / Esc 等一切缩回操作)。

## Agent 模式使用指南

Agent 模式 = 桌面挂件里的 LLM 对话 + 本机工具执行。切换后岛体变为四角星图标,
长按展开为聊天面板。

### 首次使用(必读)

1. 托盘右键 → 「模式」→ **Agent 模式**。
2. 配置 API:托盘右键 → 「设置…」→ 设置视图 → **「Agent 设置」**(设置入口
   在托盘,不在面板头部)。
3. 填写 **API Key**(DeepSeek 官方密钥)、Base URL(默认
   `https://api.deepseek.com`)、模型(默认 `deepseek-v4-flash`),保存。
4. 长按岛体展开对话面板,输入「你好」回车,开始对话。

> 也可使用 DeepSeek Anthropic 兼容端点(`https://api.deepseek.com/anthropic`,
> x-api-key 鉴权)或 OpenAI 兼容端点(地址含 `chat` 自动切换协议)。

### 对话界面

| 区域 | 说明 |
| --- | --- |
| 头部 | 状态点(待命常亮 / 忙碌呼吸)、Agent 标题、状态文案(思考中… / 执行工具中…)、右上角 ⋯ 菜单 |
| 消息列表 | 用户右侧强调色气泡、助手左侧半透明白底气泡;工具执行以卡片展示(可展开参数与结果) |
| 底部输入 | Enter 发送(中文输入法组字时不误发)/ Shift+Enter 换行;运行中按钮变「停止」 |

- **流式回复**:文字逐字渲染,思考中显示「深度思考中…」,执行工具时显示
  工具名与实时参数。
- **自动聚焦**:回复完成后自动聚焦输入框,可直接继续输入。
- **助手回复尾部**显示 token 用量(输入 / 输出 / 缓存命中)。
- **停止**:运行中点击「停止」或 ⋯ 菜单「停止生成」中止本轮。

### 头部 ⋯ 菜单与快捷切换按钮

头部右上角 **⋯** 下拉菜单(点外自动关闭):

| 菜单项 | 作用 |
| --- | --- |
| 停止生成 | 中止当前轮(仅运行中显示) |
| 新对话 | 清空当前对话(非空时先自动存档;仅已有消息时显示) |
| 对话历史 | 进入历史列表视图 |
| 工具列表 | 查看所有可用工具(内置 + MCP + 技能)及参数说明 |
| 收起面板 | 收起岛体 |

**快捷切换按钮**(鼠标悬浮在 ⋯ 上时,左侧浮现):

- 默认显示「收起面板」;
- 鼠标移到按钮上**滚动滚轮**,可在菜单各入口间逐格循环切换
  (每格有精致的内容交换动画);
- 单击执行当前选中的入口,直接跳转,无需展开菜单。

### 手动调用技能与 MCP 工具

在输入框直接输入即可让 LLM 自主决定调用什么;也可以**手动指名调用**:

- 以 **`/`** 开头 = 调技能,如 `/trump-perspective`(匹配完整名 / 去前缀 /
  模糊唯一命中);
- 以 **`@`** 开头 = 调 MCP 工具,如 `@mcp_filesystem_read_file`;
- 输入 `/` 或 `@` 时浮出候选列表(最多 6 条):↑↓ 导航 / Enter 选中 /
  Esc 关闭;剩余文本为合法 JSON 时自动作为参数。

### 本机工具(内置)

LLM 在对话中自动决定调用,全程可见(执行前展示完整参数,结果回显):

| 工具 | 作用 |
| --- | --- |
| `exec_command` | 执行本机命令(无沙箱) |
| `read_file` / `write_file` / `list_dir` | 读写文件与目录 |
| `open_url` / `open_file` | 打开网址 / 本机文件 |
| `web_search` | 联网搜索(Bing 主用,免 Key) |
| `get_time` / `system_info` | 当前时间 / 系统信息 |
| `notify` | 发送系统通知 |
| `bili` | B站数据查询与视频下载(调本机 bili-tool,下载到 `C:/Users/asus/Desktop/bilibili/bili-rs/downloads/`;完成后系统通知,回复中给出输出文件的绝对路径) |
| `doc_convert` | 文档转换(对接本机 DocFlow 服务 `http://127.0.0.1:5000`,
  需先 `python server.py` 启动;支持转 Markdown 并下载) |
| `xxt` | 超星学习通自动答题(登录 / 爬题 / 自动填写 / 提交 / 截图) |
| `switch_to_music` | 切回音乐模式 |
| `mcp_config` / `skills_config` | 对话中直接配置 MCP 服务与技能目录(自我配置) |
| `remember` / `forget` / `list_memory` / `update_memory` | 长期记忆读写 |
| `evolve_memory` | 触发记忆自我进化 |
| `delegate` | 委派子代理独立执行任务(可并行) |
| `mcp_<服务>_<工具>` | 已配置的 MCP 服务工具(按需) |
| `skill_<名字>` | 已注册的技能(按需) |

### MCP 服务接入

在 Agent 设置中添加 MCP 服务(与 Claude Code / opencode 的 MCP 配置同构):

- **stdio 传输**:启动命令 + 参数 + 环境变量(如 `npx -y mcp-remote http://…`);
- **sse 传输**:端点 URL + 请求头;
- 每个服务常驻连接,工具以 `mcp_<服务名>_<工具名>` 形式注入对话;
- 保存后下一轮对话生效;每条服务可点「测试」验证连通。

### 技能系统

- 技能 = 带 `SKILL.md`(frontmatter `name` / `description` + 使用文档)的目录;
- **默认扫描源**:`~/.claude/skills`(Claude Code)、`~/.codex/skills`(Codex)、
  `~/.config/opencode/skills`(opencode)、`用户数据/skills`(挂件自有);
- 每个技能注册为 `skill_<名字>` 工具,调用时注入完整使用文档与技能目录路径;
- 对话中输入 `/技能名` 直接调用;也可以让 LLM 直接说
  「帮我创建一个写诗技能」——它会用 `skills_config` 的 `create` 动作把技能
  写入挂件自有目录,下一轮起可用;
- 设置界面技能区**三区展示**:「灵动岛创建 / 手动导入 / 扫描到的」,可逐条移除
  或恢复(被移除的技能在 LLM 对话中也被跳过);支持从文件夹或单个 .md 文件
  **导入技能**。

### 长期记忆系统

结构化长期记忆(上限 200 条,每条 ≤ 500 字),与系统提示词共同构成助手的人格
与背景:

| 类型 | 含义 | 徽标色 |
| --- | --- | --- |
| 偏好 (preference) | 你的喜好与习惯 | 粉 |
| 事实 (fact) | 客观事实 | 蓝 |
| 工作流 (workflow) | 做事流程 | 绿 |
| 教训 (lesson) | 踩坑总结 | 黄 |

- **对话沉淀**:说「记住:…」即写入长期记忆(自动去重);
- **人工管理**:Agent 设置 → 长期记忆区,添加 / 编辑 / 删除条目;
- **记忆导出**:设置界面记忆区「导出」按钮,导出为 JSON 文件,可再导入;
- **类型选择**:添加框左侧的分类按钮,点击展开类型浮层;也可以把鼠标移到
  按钮上**直接滚轮**逐格循环切换类型(下拉仍保留)。

### 自我进化

Agent 设置 → 自我进化区:「运行记忆进化」按钮(或让 LLM 调用 `evolve_memory`
工具)——一个独立评估代理对记忆逐条评审(冗余 / 一致 / 时效 / 可操作 / 价值),
提出带假说的改进,应用后复评,**评分严格提高才接受为新版本**并存档,
否则自动回滚。可查看进化日志、回滚到上一版本、清除所有版本。

### 对话历史

- 每次「新对话」自动把当前对话存档(上限 20 条);
- ⋯ 菜单 → 「对话历史」:标题(首条用户消息)+ 时间(今天 HH:MM / 昨天 /
  M月D日),点击加载(替换当前对话并从历史移除),行内删除(带离场动画);
- 历史持久化,重启不丢。

### 工具列表视图

⋯ 菜单 → 「工具列表」:展示当前全部可用工具(内置 + MCP + 技能)的名称、
描述与参数 JSON Schema,卡片可展开。

### Agent 设置(全部字段)

## 已知限制

- **进度条拖动跳转**依赖客户端支持 SMTC 跳转(QQ音乐不支持,操作后岛内提示,
  进度条显示系统真实状态);支持记忆按平台持久化,不重复提示。
- **播放模式(循环 / 随机)**:本地播放器始终有效;外部平台走 SMTC 新版 API,
  客户端不支持时指令被拒并提示。
- **播放列表无法与外部平台双向同步**:SMTC 不提供播放列表读取 / 写入能力,
  播放列表只对本地播放器有效。
- **歌词源为在线查询**:歌词来自各音乐平台公开接口,可能缺失或匹配偏差;
  酷我音乐歌词接口已封闭,自动回退 QQ 歌词兜底。
- 系统媒体读取依赖 Windows 10/11 的 `System32\WinMetadata`。
- 卸载安装版会**删除全部用户数据**(上传音乐 / 背景 / 字体 / 配置 / 记忆)。

## 常见问题

**Q: 挂件没显示正在播放的音乐?**
先确认音乐客户端正在播放、且该客户端支持 SMTC(QQ音乐 / 网易云 / 酷狗 /
酷我 / 汽水音乐等)。部分客户端需在设置中开启「显示桌面歌词 / 系统集成」类
选项。

**Q: Agent 模式回复报错 / 一直转圈?**
检查 Agent 设置中的 API Key 与 Base URL 是否正确、网络是否可达;
DeepSeek 官方端点无需代理。

**Q: 拖进度条没反应?**
当前平台不支持 SMTC 跳转(如 QQ音乐),岛内会提示并回退。

**Q: 歌词对不上 / 一直不显示?**
设置 → 歌词 API 切换歌词源(QQ音乐源兼容性最好);确认「自动切换」开关;
自定义 URL 模板支持 `{title}` / `{artist}` 占位。

**Q: 如何重置全部配置?**
退出挂件后删除 `%APPDATA%\dynamic-island` 目录(上传音乐 / 背景 / 字体 /
设置 / Agent 记忆都在里面);安装版卸载时会自动删除。

**Q: 挂件挡住了其他窗口?**
托盘取消勾选「总在最前」;或右键长按把岛体拖到屏幕边缘。

## 技术架构

详见 [WIDGET-README.md](WIDGET-README.md)(实现级技术笔记)。概览:

- **双入口共享一个组件**:`src/`(Web 演示版)与 `widget/`(桌面挂件)共用
  `DynamicIsland.tsx` 岛体组件,差异全部靠 CSS 覆盖与可选 props;
- **数据源双轨**:`useSystemMedia`(SMTC 外部平台)与 `useMediaPlayer`
  (本地播放器)并存,切换时双向暂停;进度显示 = 锚定基准 + 本地时钟流逝
  (平滑防抽搐),歌词定位单独成轨跟随平台上报(与歌词对齐);
- **主进程**:透明无边框窗口 + 点击穿透 + 右键长按拖拽(防漂移三件套)、
  托盘、SMTC 桥接以 utilityProcess 运行(崩溃自动重启)、配置持久化;
- **Agent 引擎**:主进程内运行的 LLM 循环(无状态,渲染端回传完整历史),
  Provider 自动判定(DeepSeek Responses 默认 / Chat / Anthropic),
  工具系统模块化,零第三方依赖,esbuild 打包;
- **调试工具**:`WIDGET_SCREENSHOT=<path>` 加载后自动截图,
  `WIDGET_SCREENSHOT_MODE` 支持 expanded / layout / theme / stress / test /
  agent(严格 UI 巡检,见 WIDGET-README)。
