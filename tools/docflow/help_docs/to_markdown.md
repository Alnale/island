# 转 Markdown 模式

## 模式概述

将 PDF、DOC/DOCX 文档转换为 Markdown 格式，保留文档结构、表格和图片。支持从转换结果直接生成思维导图（SVG/PNG）。

---

## 输出设置详解

### 输出（DOC 输入时可用）

当输入为 DOC/DOCX 文件时，系统先通过 Microsoft Word 转换为 PDF，再提取为 Markdown。以下选项控制中间 PDF 的生成质量：

#### PDF 版本
- **PDF 1.7** - 现代标准，推荐
- **PDF 1.6** - 兼容性较好
- **PDF 1.5** - 广泛兼容

#### 页面大小
- **A4** - 国际标准，最常用
- **Letter** - 北美标准
- **Legal** - 法律文件标准

#### 页面方向
- **纵向** - 标准文档方向
- **横向** - 宽屏方向

---

### 质量（DOC 输入时可用）

#### 图片 DPI
- **600** - 无损印刷级，文件较大
- **300** - 打印质量，推荐标准
- **150** - 平衡质量与文件大小
- **72** - 屏幕显示质量，文件最小

#### 嵌入字体
- **开启** - 在中间 PDF 中嵌入字体，保留排版样式
- **关闭** - 依赖系统字体，文件较小

#### 无损图片
- **开启** - 禁用图片压缩，保留原始精度
- **关闭** - 启用图片压缩，减小文件体积

---

### 安全（DOC 输入时可用）

#### 密码保护
- **开启** - 转换的中间 PDF 需要密码才能打开
- **关闭** - 无密码保护

#### 允许打印
- **开启** - 允许打印中间 PDF
- **关闭** - 禁止打印

#### 允许复制
- **开启** - 允许复制中间 PDF 内容
- **关闭** - 禁止复制

---

### 内容

#### OCR 识别
- **开启** - 对扫描页面进行 OCR 识别，提取可编辑文字
- **关闭** - 仅处理原生 PDF（文字可选中），跳过扫描页面

> 提示：PDF 输入时，OCR 引擎状态会显示在设置面板中。绿色表示 RapidOCR 可用，蓝色表示 Tesseract 可用。

#### 提取图片
- **开启** - 提取文档中的图片，保存到同级 `media/` 目录
- **关闭** - 仅提取文字，忽略图片

---

### 转换后

#### 自动下载
- **开启** - 转换完成后自动下载 Markdown 文件
- **关闭** - 仅在历史记录中查看

#### 保留历史
- **开启** - 在历史记录中保存转换记录
- **关闭** - 转换后不保留记录

---

## 转换流程

### PDF 输入
1. 使用 PyMuPDF 逐页分析文本块、图片和表格
2. 识别标题层级（基于字体大小和粗细）
3. 提取表格并转换为 Markdown 管道表格格式
4. 提取图片到 `media/` 子目录
5. 组装为完整的 Markdown 文档

### DOC/DOCX 输入
1. 通过 Microsoft Word COM 接口转换为 PDF
2. 按照 PDF 流程提取为 Markdown
3. 若 Word 不可用，使用 `python-docx` 直接提取（功能受限）

### 混合文档
系统自动检测页面类型（原生/扫描），按类型分别处理后合并结果。

---

## 思维导图生成

转换完成后，可在 Markdown 预览界面生成思维导图：

### 使用方法
1. 在历史记录中点击已完成的转 MD 任务
2. 在预览区域点击 **脑图 SVG** 或 **脑图 PNG** 按钮
3. 等待生成完成，文件自动下载

### 格式说明
- **SVG** - 矢量格式，无限缩放不失真，推荐使用
- **PNG** - 位图格式，通用性好

### 系统要求
- 需要安装 **Node.js**（用于运行 kmind 渲染引擎）
- 需要安装 **Chrome / Edge / Brave** 浏览器（用于无头渲染）
- 首次使用时系统会自动检测可用性

### 注意事项
- 思维导图基于 Markdown 标题层级生成
- 过长的标题可能导致显示重叠，建议保持标题简洁
- 生成超时时间：120 秒

---

## Markdown 预览

转换完成后支持两种预览模式：

### 渲染视图
以格式化的方式展示 Markdown 内容，包括标题、列表、表格、代码块等。

### 源码视图
显示原始 Markdown 文本，可查看完整语法。

通过预览区域顶部的切换按钮可在两种视图间切换。

---

## 使用建议

### 学术论文
- OCR 识别：开启
- 提取图片：开启
- 图片 DPI：300
- 适合后续整理笔记和生成思维导图

### 扫描文档
- OCR 识别：开启
- 提取图片：关闭（OCR 已提取文字）
- 确保 OCR 引擎状态为绿色（RapidOCR 可用）

### 纯文本文档
- OCR 识别：关闭
- 提取图片：关闭
- 转换速度最快

### 生成思维导图
- 确保文档有清晰的标题层级结构
- 标题层级建议不超过 4 级
- 每级标题建议不超过 30 个字符
