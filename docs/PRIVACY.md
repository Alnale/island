# 隐私说明

灵动岛默认在本机保存设置、记忆、会话状态和审计日志。Agent 对话会按你选择
的 Provider 发送到相应云端服务；MCP、技能和本地工具可按其自身配置访问网络或
本地文件。NapCat 启用后会处理 QQ 消息和媒体。

API Key、Provider 凭据和 MCP 的 `env/headers` 使用操作系统安全存储加密落盘。
会话审计日志默认只保存在本机，采用轮转保留；其中可能含模型可见的对话上下文。

“恢复出厂设置”会删除应用设置、凭据、主人身份、记忆、会话、媒体库和本地审计
日志，并自动重启。"清除工具数据"只删除工具下载、登录态和截图，不删除挂件设置。
